# DevFlow — курсовой проект по серверной веб-разработке

**DevFlow** — полнофункциональное учебное веб-приложение для разработчика на **Flight PHP 3**, PHP 8.1+, MySQL, HTML, CSS и JavaScript.

## Возможности

- Современная адаптивная главная страница и навигация.
- **Регистрация и вход**: хеширование паролей, сессии, защищённые формы.
- **Менеджер задач**: создание, выполнение, удаление, индивидуальные данные пользователей.
- **База знаний**: статьи из MySQL, поиск, отдельная страница статьи и nickname автора из отдельного запроса к таблице `users`.
- **Калькулятор**: вычисление стоимости проекта по типу, количеству страниц, интеграциям, уровню дизайна и сроку. Расчёт на сервере, живой предпросмотр на JavaScript, сохранение истории для авторизованных пользователей.
- **Обратная связь**: серверная проверка и сохранение обращений в MySQL.

## Установка в XAMPP (Windows)

**Требуется:** PHP 8.1+, расширение `pdo_mysql`, XAMPP (Apache и MySQL), [Composer](https://getcomposer.org/download/).

1. Скопируйте папку `devflow-coursework` в `C:\xampp\htdocs\`.
2. Откройте VS Code → **Терминал** в папке проекта и выполните:
   ```powershell
   composer install
   ```
   Composer скачает настоящий backend-фреймворк **Flight PHP** в папку `vendor`. Без этого шага сайт покажет сообщение об установке.
3. Запустите Apache и MySQL в XAMPP. В `http://localhost/phpmyadmin/` создайте БД `devflow` с кодировкой `utf8mb4_unicode_ci`. **Откройте эту базу** и импортируйте файл `database/schema-hosting.sql`.
4. Скопируйте `app/config.example.php` → `app/config.local.php`, при необходимости заполните свои данные MySQL (в стандартном XAMPP: `127.0.0.1`, база `devflow`, пользователь `root`, пароль пустой).
5. Откройте в браузере:
   **http://localhost/devflow-coursework/public/**
6. Зарегистрируйте **свою** учётную запись. Пользователей с никами `nastya_dev` и `alex_web` SQL создаёт только как демонстрационных авторов: у них нет пароля.

Если команда `composer` не распознана — установите Composer для Windows. PHP может находиться по пути `C:\xampp\php\php.exe`.

### Альтернатива — встроенный сервер PHP

Из папки проекта после `composer install` запустите:
```powershell
php -S localhost:8080 -t public public/router.php
```
Адрес: `http://localhost:8080/`. База данных MySQL всё равно требуется.

## Работа с InfinityFree

InfinityFree не предоставляет обычный терминал Composer, поэтому зависимости нужно установить **на компьютере** и уже после этого загрузить сайт. В корне проекта выполните:

```powershell
php tools/build_hosting.php
```

Скрипт создаст `dist/htdocs` с нужными папками, включая `vendor` (фреймворк), и защитой для приватных файлов. Загрузите **содержимое** `dist/htdocs` в `htdocs` хостинга, создайте там `_private/app/config.local.php`, укажите MySQL реквизиты, импортируйте SQL в свою базу хостинга. Полная инструкция: `docs/HOSTING.md`.

Если у вас уже три бесплатных аккаунта InfinityFree, можно разместить курсовую в отдельной папке существующего хостинга, но потребуется указать правильный URL и проверить маршруты. Для публичной демонстрации лучше использовать учебные данные.

## Демонстрационные сценарии для защиты

1. Открыть главную страницу, объяснить интерфейс и маршруты.
2. Перейти в базу знаний, найти статью, открыть её и показать nickname автора из таблицы `users`.
3. В калькуляторе изменить число страниц, затем отправить форму POST и показать расчёт PHP.
4. Зарегистрировать личный аккаунт, добавить задачу, отметить выполненной, удалить.
5. Отправить сообщение через форму обратной связи и найти его в таблице `feedback` в phpMyAdmin.
6. Показать в коде маршруты Flight, подготовленные SQL-запросы, CSRF и `password_hash`.

## Безопасность

- PDO prepared statements, `htmlspecialchars`, CSRF, `password_hash`/`password_verify`.
- У каждого пользователя свои задачи. Адресная форма обратной связи сохраняет данные, но не отправляет электронную почту.
- Реальные пароли исключены из Git; не показывайте `config.local.php` в отчёте или на скриншотах.
- Это **учебный проект**, а не готовый публичный коммерческий сервис. Для реальной эксплуатации нужны отдельная политика обработки персональных данных, мониторинг, более строгая защита от автоматизированных запросов и HTTPS.

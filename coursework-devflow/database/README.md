# База данных

1. В phpMyAdmin создайте базу `devflow` (локально) или собственную базу в панели хостинга.
2. Выберите эту базу слева.
3. Нажмите «Импорт», загрузите `schema-hosting.sql`.
4. Убедитесь, что появились таблицы `users`, `articles`, `tasks`, `estimates`, `feedback`.
5. Два автора и четыре статьи создаются автоматически. Повторный импорт не требуется.

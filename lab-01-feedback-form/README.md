# Feedback form — самостоятельная работа

Двухстраничный PHP-сайт с формой обратной связи и выводом результата `get_headers()`.

Состав

- `index.php` — форма обратной связи, отправка POST на `https://httpbin.org/post`;
- `headers.php` — запрос HTTP-заголовков с `https://httpbin.org/get` и вывод в `textarea`;
- `style.css` — оформление обеих страниц;
- `logo.png` — логотип Московского Политеха.

Локальный запуск

1. Установите PHP 8.0+ (или XAMPP / OpenServer).
2. Откройте терминал в папке проекта.
3. Выполните `php -S localhost:8000`.
4. Откройте `http://localhost:8000/index.php`.

PHP должен иметь возможность устанавливать HTTPS-соединения и параметр `allow_url_fopen = On`.

Проверка

1. Заполните форму тестовыми данными и отправьте — браузер должен перейти на `https://httpbin.org/post`, где будут отображены отправленные поля (в формате JSON).
2. На второй странице должны появиться реальные заголовки HTTP-ответа. Их состав меняется в зависимости от сервера.

Примечание: форма отправляет данные напрямую во внешний тестовый сервис httpbin.org. Не вводите в неё реальные персональные данные.

Размещение

- GitHub — для хранения исходного кода.
- PHP-хостинг — для работающего сайта. GitHub Pages не исполняет PHP.

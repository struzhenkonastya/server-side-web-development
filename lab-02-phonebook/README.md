Лабораторная работа №2 — Записная книжка

Технологии: PHP 8.0+, MySQL, HTML, CSS  
Главная страница: `index.php`

Веб-приложение для хранения и изменения контактных данных. Все переходы между разделами происходят только через `index.php`**. Остальные PHP-файлы подключаются как модули и закрыты от прямого посещения.

Что выполнено

- Просмотр контактов в таблице, по 10 записей на страницу.
- Пагинация с номерами страниц и рамкой 2 px при наведении.
- Сортировка по порядку добавления, фамилии и дате рождения по возрастанию.
- Главное меню с синими кнопками и красным активным пунктом.
- На странице просмотра — дополнительное, более компактное меню сортировки со своим красным активным пунктом.
- Добавление контакта с сообщениями «Запись добавлена» / «Ошибка: запись не добавлена».
- Редактирование контакта после выбора его из алфавитного списка; при первом открытии выбран первый контакт.
- Удаление по ссылке «Фамилия И.О.» с выводом сообщения «Запись с фамилией ... удалена».
- Девять полей каждого контакта: фамилия, имя, отчество, пол, дата рождения, телефон, адрес, email и комментарий.
- Защита от SQL-инъекций через PDO-параметры, экранирование HTML и токены против сторонних запросов.

Файлы

| Файл | Назначение |
| --- | --- |

| `edit.php` | Форма, список выбора и обработка редактирования |
| `delete.php` | Список и обработка удаления |
| `db.php` | Подключение PDO к MySQL |

| `config.example.php` | Стандартное подключение к локальной базе XAMPP |

Запуск на компьютере (Windows / XAMPP)

1. Распакуйте папку `lab-02-phonebook` и откройте её в VS Code.
2. Запустите Apache и MySQL в XAMPP Control Panel. Для базы данных нужен именно MySQL; Apache потребуется для `phpMyAdmin`.
3. Откройте `http://localhost/phpmyadmin/` в браузере.
4. На главной странице phpMyAdmin выберите вкладку «Импорт», выберите файл `schema.sql` из распакованной папки и нажмите «Импорт» / «Вперёд». В результате должна появиться база `phonebook` и таблица `contacts` с 12 тестовыми строками.
5. В VS Code откройте терминал в папке `lab-02-phonebook`** и выполните:

   ```powershell
   & "C:\xampp\php\php.exe" -S localhost:8001
   ```

6. Откройте `http://localhost:8001/index.php` — появится таблица контактов и ссылки страниц `1` и `2`.
7. Если MySQL работает с нестандартными логином или паролем, создайте файл `config.local.php` на основе `config.example.php` и укажите свои значения. 

> Встроенный PHP-сервер можно использовать для проверки страниц и модулей, но он не читает `.htaccess`. Защита прямого доступа обеспечивается и в самом PHP-коде каждого модуля.

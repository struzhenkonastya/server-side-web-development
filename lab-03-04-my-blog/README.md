«Мой блог» — лабораторные №3, №4 и №5

Дисциплина: Серверная веб-разработка.

Это обновление уже существующего проекта `lab-03-04-my-blog`: оформление сохранено, добавлена страница просмотра статьи с nickname её автора из MySQL. Сайт один, хостинг можно использовать прежний.

Что реализовано

- №3 — `PagesController::sayBye(string $name)` и маршрут `/bye/Настя`.
- №4 — динамический `<title>`, заголовок по умолчанию «Мой блог», для `/hello/Настя` — «Страница приветствия».
- №5 — `ArticlesController::show(int $id)`: сначала запрос к `articles`, затем **второй отдельный запрос к `users` по user_id**, вывод `nickname` в `views/article.php`.

Запуск на компьютере через XAMPP

1. Сделайте резервную копию старого проекта.
2. Замените содержимое `C:\xampp\htdocs\lab-03-04-my-blog` файлами этого проекта (скопируйте **содержимое** папки, а не саму папку повторно).
3. Запустите **Apache и MySQL** в XAMPP.
4. Откройте `http://localhost/phpmyadmin/`.
5. На уровне **сервера** (без выбора другой базы) откройте **Импорт** и выберите `schema-local.sql`. Он создаст базу `my_blog`, таблицы `users` и `articles` и две учебные статьи.
6. Файл `config.example.php` уже содержит типовые настройки XAMPP: `127.0.0.1`, пользователь `root`, без пароля. Если у вас другие реквизиты, создайте **локальный** `config.local.php`, скопировав содержимое примера и изменив значения.
7. Откройте `http://localhost/lab-03-04-my-blog/` и нажмите «Читать статью и узнать автора».

Проверка:

- `/` — главная страница (две карточки статей).
- `/hello/Настя` — приветствие; заголовок браузера «Страница приветствия».
- `/bye/Настя` — «Пока, Настя».
- `/articles/1` — статья с автором `nastya_dev`.
- `/articles/2` — статья с автором `alex_web`.

Лабораторная №5

Реализовано получение автора статьи из таблицы users с помощью дополнительного SQL-запроса в ArticlesController::show(). Nickname автора выводится в шаблоне статьи.
